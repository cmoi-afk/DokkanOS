Les missions de Survie météorique enregistrées depuis une capture sont rapprochées automatiquement des références du catalogue après l'import de la sauvegarde. Les résultats, les essais et les récompenses déjà déclarées récupérées sont préservés. Aucune victoire n'est créée par la mise à jour.

Validation : catalogue, missions, vingt phases, gestion des éveils, images locales, mode hors ligne, Frontier, missions EX liées, interactions DOM et migration des sauvegardes (conservation, absence de validation sans preuve, réexécution et annulation sur erreur de stockage).

Les valeurs de PV/ATT/DÉF non publiées pour les nouvelles cases Frontier restent explicitement inconnues. Les événements historiques hors du périmètre de cette mise à jour conservent leurs vérifications antérieures.

Sources publiques : [DokkanInfo GLOBAL FR](https://glbfr.dokkaninfo.com/cards), [Dokkan Battle France](https://dbz-dokkanbattle.com/), [DokkanStats Frontier](https://dokkanstats.com/fr/frontier).
