# DokkanOS V2 — reconstruction propre

Cette reconstruction est indépendante des catalogues V0/V1.

## Règles
- Aucun nombre cible fixé à l'avance.
- Aucun ID ou mapping image hérité automatiquement.
- Une source structurante est auditée avant import.
- Les cartes non jouables sont exclues sur critères documentés.
- Les images finales sont stockées localement.
- Le catalogue est audité avant toute intégration dans l'interface.
